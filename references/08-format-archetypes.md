# Format archetypes and corpus benchmarks

> **Starting points, not hard rules.** Every number in this file is a measured tendency from a reference corpus, not a target and not a gate. The brief, the user's decision, and the measured reference blueprint of the chosen reference always win over this file.

## Corpus benchmarks (launch films)

Source: the refs.video corpus FAQ, 1,952 measured launch films, October 2026. These are the site's published statistics, not measurements made by this skill.

| benchmark | value |
|---|---|
| median launch film duration | 53 s |
| average cut interval | every 3.5 s (16 cuts per minute) |
| most common tempo | 120 BPM |
| most common first on-screen word | "Introducing" |
| ending | more than half of launch films end on the brand name itself (brand end card) |

## How to use this file

- In Phase 3, pick the archetype whose format matches the brief before writing the free concept (section 3.1). Record the archetype name in the concept summary. The archetype sets the rhythm envelope only (duration range, cut pace, ending habit); the visual concept stays original, one video, one new concept.
- Pace is a property of the format, not a universal number: published ranges run from 0 to 58.8 cuts per minute. A pace outside the archetype range is allowed, but then it is a deliberate deviation and is noted in the concept summary.
- For a launch or product film brief, show the corpus benchmarks to the user in Phase 1 as comparison material for the duration and ending decisions. They never override the short-form defaults in section 1c on their own.
- Loudness caution: measured reference masters in this corpus sit near -12.4 to -12.7 LUFS integrated with true peaks up to -0.6 dBFS. Those masters would fail Gate E. The Gate E targets in this skill (-14 +/-1 LUFS, true peak at or below -1.2 dBTP) do not change; see section 7.6.
